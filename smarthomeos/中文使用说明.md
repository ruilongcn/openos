## 🚀 快速开始

### 方式一：统一控制器（推荐）
```bash
cd F:\openos\smarthomeos
python smart_home_controller.py
```
这将启动一个统一的中文界面，包含所有功能！

### 方式二：单独启动OpenClaw
```bash
cd F:\openos\smarthomeos
python -m modules.openclaw.app
```

### 方式三：启动主服务
```bash
cd F:\openos\smarthomeos
python core/services/smarthomeos_service.py
```

## 💡 使用示例

### 使用统一控制器
1. 运行 `python smart_home_controller.py`
2. 点击首页的功能卡片
3. 在对应标签页中测试功能

### 使用OpenClaw
1. 运行OpenClaw界面
2. 点击"新建"创建代理
3. 在左侧选择一个代理
4. 点击"启动"
5. 在聊天窗口发送消息
